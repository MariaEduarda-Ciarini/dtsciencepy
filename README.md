# 🐍 dtsciencepy

Repositório criado para organizar meus estudos, experimentos e projetos pessoais utilizando **Python**, com foco em **desenvolvimento web**, **banco de dados** e **análise de dados**.

---

## 📁 Estrutura do Repositório

### 🔧 Flask
Sistema de gerenciamento de jogos construído com **Flask** e **MySQL**.

- Cadastro, edição e exclusão de jogos
- Integração com banco de dados via SQLAlchemy
- Upload de imagens (capas)
- Templates com Jinja2
- Estrutura modular com boas práticas


---

### 📊 AnaliseDados
Scripts de análise de dados utilizando bibliotecas como:

- `pandas`
- `matplotlib`
- `numpy`

Projetos de leitura de planilhas, agrupamento, filtragem e visualização gráfica.


---

### 🤖 AutomacoesPython
Scripts simples de automação com Python para:

- Abertura de sistemas
- Simulação de teclas com `pyautogui`
- Automatização de processos repetitivos


---

## 💡 Tecnologias Utilizadas

- Python 3.x

- MySQL
- Pandas / NumPy / Matplotlib
- PyAutoGUI
- Git
